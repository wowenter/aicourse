# Kaspi gateway

Основано на открытом проекте [tapter-dev/kaspi-pos-automation](https://github.com/tapter-dev/kaspi-pos-automation) (лицензия MIT, см. LICENSE).

Изменения для этого проекта:
- доступ к `/api/*` только с заголовком `X-Gateway-Key` (переменная `GATEWAY_KEY`), веб-панель отключена;
- все файлы состояния (ключи устройства, отслеживаемые платежи, логи) — в папке `DATA_DIR` (на Railway — постоянный том `/data`);
- вебхук задаётся переменными `WEBHOOK_URL` и `WEBHOOK_SECRET`;
- подробные логи с токенами — только при `LOG_HTTP=1`;
- повтор вебхука, если сервер ответил не 2xx.

⚠️ Это неофициальная интеграция с Kaspi Pay. Kaspi может в любой момент изменить API или ограничить такие подключения.
